# 南澜记 V3.3 · 南街灯起

古风场景探索与生活经营开发试玩。第一卷 18 段主线，第二卷 18 段主线，19 处地图场景。男女主角共享剧情。

## 继续旧进度

保留 V2.x 的 `nanlan_v20` 存档键。请在原网址和原浏览器更新游戏，选择「继续当前存档」，不要另开新旅程。
第一卷 M20 完成后，到正厅「新春家议」开启第二卷。原有物资、铜钱、人物选择与第一卷进度保留。
跨网址或浏览器时，在旧游戏行囊导出存档，再在新网址行囊导入。浏览器本地存档不会随 GitHub 文件同步。

## 第二卷流程

1. 家宴后的铺讯 → 早市、午间、午后三时观察 → 亲查榕荫铺与桥口铺。
2. 回正厅核算家用、租金、押金与修缮；M12 签下自修、房东修补或短期试租条款。
3. 请林师傅检修柜架、试走陈列通道、挂铺号；仓房装实货，付运费发车，再到店验收。
4. 选择陈列与时段留货，逐件调价，亲手开门；听旧客意见、成交、回复行商大单。
5. M18 核对首日实际收支后，到铺门点灯。亏损也可诚实结账；过夜后可补核旧日账目。
6. 与邻铺议竞争与转介，履行熟客定金单、县集生产单，向南澜供货者验货付款。
7. 回家商议轮值，兑现邻铺转介，完成三个不同营业日的真实闭账，再定下一阶段方向。

每天有六位普通来客，交易须亲自点击；回卧房睡一夜后刷新。订单价格确认后固定，预订定金在交货时抵扣。家中、在途、铺内库存分别记录，承诺给顾客的实货不会被普通零售取走。租金预付、押金与经营分摊分开核算，闭账不重复扣款。原有六段版第二卷存档会接续新增剧情，旧租金、库存、收入及完成纪念保留。第二卷完结后可继续经营。

县城沿用既有完整原画。两种陈列选择以铺面面板与记录呈现，当前不含自由拖放家具或两套独立室内原画。

## 声音

点击声音设置可开启、试听两声提示、调节音量。文件全部为项目程序合成，来源见 AUDIO_PROVENANCE.md。首次播放需要点击；若仍无声，检查标签页静音和设备媒体音量。

## GitHub Pages

将发行包中 `index.html`、`assets/` 及其他运行文件上传至仓库根目录，不要只上传 ZIP。
在仓库 Settings → Pages 中选择部署分支与根目录。更新后刷新页面，确认版本 V3.3。

## 开发与验证

运行文件在 dist/。`python build_data.py` 重建数据；`python synth_audio.py` 可重建原创音效。
验证：`node engine.test.cjs`、`node volume2.test.cjs`、`node navigation.test.cjs`、`node journey.test.cjs`、`node audio.test.cjs`、`node resource-ui.test.cjs`、`node rare-resources.test.cjs`。先运行第一卷测试以生成后续流程使用的起点存档。

## 人物素材

16 个透明底人物：14 个 NPC 角色与男女主角，统一画风，按脚点排序并随昼夜调整明暗。人物谱同步显示。当前为 2D 静态精灵，不含 3D 网格、骨骼绑定或完整方向动画。来源与生成说明见 NPC_ASSETS.md。

## V3.2 场景整理

取消场景标签到物件的连接线。采集物与菜畦不再显示悬浮名称，保留原画物件、轻微暖光提示和触控热区。靠近或选中后，在右下角显示名称与操作；也可从「场景互动」或舆图查找物资。
