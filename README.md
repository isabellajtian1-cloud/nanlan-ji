# 南澜记 第一卷开发试玩 V2.7

这是根据《南澜记游戏计划书 V1.1》同步改造的网页试玩版本。使用原有场景插画，新增门前交接的逻辑入口；修缮、清草、种植与灯火通过状态画面表现。

## 玩法与完成条件

在场景中走近物件与人物，实际拾取、修补、种植、制作、交付，再回访家人与邻里。第一卷以 M20「岁末满庭」家宴作为完成条件，共 18 段主线。M12 看铺与 M18 首店开张保留编号，状态为第二卷预留。

体力不足、材料不足、涨潮或错过试摊窗口时，当前行动无法执行；通过休息、补料或下一轮机会重试。没有永久死亡和错过窗口后清空进度的惩罚。

## 运行与上传

这是静态网站，无需账号、后端或构建步骤。dist/ 是可部署目录。

部署目录 dist/ 包含 index.html、三个 CSS、各个 .js 和 assets/。另提供独立打包的 GitHub 单文件版：解压 Nanlan_V26_GitHub.zip 后，仅用其中的 index.html 替换原仓库同名入口。不要把 ZIP 本身上传为主页，也不要命名为 index (2).html。

源代码按数据、状态引擎、插画辅助、游戏界面和地图拆分。插画按场景加载，首屏不预载全部原画。

- 真实浏览器另外检查开局说明、地图、M01—M04 的物件操作、时钟与保存恢复。
- 内容仍是开发试玩。物品产量、价格、等待时间与对白长度需要后续试玩校准。部分后续主线通过简化的场景行动和对白表达，尚未制作完整演出与人物动画。
