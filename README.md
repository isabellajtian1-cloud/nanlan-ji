## V6.10.6 · 一路相续

六卷主线与番外整体开发试玩。点击[网页版](https://isabellajtian1-cloud.github.io/nanlan-ji/?v=6106)游玩。

与家人分过第一顿热饭后，点庭院灶台的「添料试菜」。试成的菜能起名、复做，或从行囊里的食谱簿取一碗吃。赤豆、栗子、海鲞、甘蔗和生姜可向村中乡邻余粮补购。

与家人吃过第一顿饭，从庭院灶台打开「市井食笺」。二十四道菜饮分四栏。南澜村可按方购买缺料，夏天可在庭院鱼塘采荷叶。镇集摊布收当季成菜，第二卷的茶馆和客栈各有每日点单。糟鱼、糟蟹封坛后到次日六时可以揭坛。菜页内附中英文说明与出处链接。

人物使用重新制作的步行图集。主角与街坊的影子先落在地面上，衣摆按脚底的前后位置遮挡。

## 从完整包运行

解压全部文件。根目录的 `index.html` 是游戏入口。也可以在该目录启动静态文件服务器，例如运行 `python -m http.server 8000`，然后访问 `http://localhost:8000/`。游戏无需安装 npm 依赖或编译。

## 上传到 GitHub Pages

1. 将解压后的全部文件和子目录按原结构放入网站发布目录。
2. 确认 `index.html` 直接位于发布目录，提交到原仓库。
3. 沿用仓库现有的 Pages 设置。部署完成后打开网页，标题应显示 V6.10.6「一路相续」。

## 游玩与存档

用方向键或 WASD 行走，按住 Shift 快步，也可以点选地面或触控行走。到门前确认后进入下一处。饭桌、床和书案可直接点选。榕溪石径位于南澜村东边，和家人吃过第一顿热饭后可前往。

种植从后院第一块小畦开始。其他菜畦需要翻土，之后可扩整药田。选种播下，浇水后随游戏时辰生长，成熟时收进行囊。

在同一浏览器和网站继续旅程，可读取原存档。换设备或网址前，可以从行囊导出存档，在另一处的启程页导入。
