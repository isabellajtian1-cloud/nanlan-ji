南澜记 V3.9.19 · GitHub Pages 上传说明

1. 先解压 ZIP，不要把 ZIP 文件本身直接上传到仓库。
2. 把 index.html、整个 assets 文件夹，以及同层的全部 .js、.css、_headers 文件上传到 GitHub 仓库根目录。
3. 上传后请在仓库中确认以下文件都存在：
   assets/gate-v27.webp
   assets/gate-v27.jpg
   assets/yard-v22.webp
4. 在 Settings → Pages 中选择部署分支，并选择 /(root) 作为发布目录。
5. 等 GitHub Pages 部署完成后，重新打开网址；若手机仍显示旧页面，请强制刷新或清除该网址的缓存。

本版为旧宅门前图片加入 WebP 主图与 JPG 备用图，并延长手机端加载等待时间。旧存档结构、剧情流程和数值均未改变。

跨网址更新前，请先在旧网址导出存档，再在新网址导入。浏览器存档不会跨网址自动同步。
