《南澜记》V3.9.18 · 田间劳作

GitHub Pages 上传方法：
1. 解压本压缩包。
2. 将解压后的全部文件和 assets 文件夹上传到 GitHub 仓库根目录。
3. 在仓库 Settings → Pages 中选择 Deploy from a branch。
4. Branch 选择 main，文件夹选择 /(root)，保存后等待 GitHub 发布。

请保持 index.html、game.js、style.css 和 assets 文件夹的相对位置不变。
若从旧网址换到 GitHub Pages，请先在旧版游戏的行囊中导出存档，再在新网址导入；浏览器进度不会跨网址自动同步。
